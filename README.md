# Web Piano 网页钢琴

纯前端钢琴网站，无需后端与外部音频文件，音色由 Web Audio API 实时合成。
内置下落式练习模式与漏键暂停机制。

## 使用

双击 index.html 用浏览器打开即可弹奏。首次点击页面后音频才会激活（浏览器策略）。

## 自由弹奏

- 88 键（A0-C8）完整键盘
- 三种音色：钢琴 / 风琴 / 电子琴
- 鼠标触摸弹奏，支持按住滑奏
- 键盘映射：A W S E D F T G Y H U J K（从 C4 起，黑键为 W E T Y U）
- 左右方向键移调，上下方向键升降八度
- 音量、移调、音名显示、录音回放

## 练习模式

1. 顶栏选择曲目，点 练习
2. 音符从顶部落下，到发光判定线时按对应琴键
3. 判定（按对键 + 时间）：Perfect（180ms 内，+100）/ Good（360ms 内，+70）/ OK（提前 850ms 内，+35），
   音符还没到线、隔着一段距离也能按中，离得越远分越低
4. 按到旁边的键也能中：相邻 1 个键（含黑键）+25，中间隔 1 个键 +10，再远不识别；
   漏键暂停补按时同样适用（不再随机扣分）
5. 漏键暂停：音符过线 150ms 后仍未按时轨道立即冻结，全部音符停在原地（此时后续音符都在线上方），
   漏键音符吸附在判定线上闪烁，状态栏提示按哪个音、对应哪个键盘键
6. 补按：按下对应键或点击琴键，恢复下落，得 +50（减半分）；恢复时所有音符保持当前高度
   无缝继续下落，不会跳变；一次按键只判定一个音符，不会连锁
7. 曲终显示总分、完美数、良好数、擦边数、邻键数、补按数

## 自定义曲目（`js/custom.js`）

打开 `js/custom.js`，把曲子加进 `CUSTOM_SONGS` 列表，保存后刷新页面，即可在曲目下拉框里选到。

简易写法（推荐）：按顺序写音名，每个音默认 1 拍；`"音名:N"` 表示占 N 拍；`"R:N"` 表示休止 N 拍。
音名格式：`C4 D4 E4 F4 G4 A4 B4 C5`，升降号用 `#` 或 `b`（如 `C#4`、`Bb3`）。

```js
var CUSTOM_SONGS = [
  { name: '我的小曲', bpm: 100, seq: ['C4','C4','G4','G4','A4:2','R:1','G4:2'] }
];
```

也支持完整写法：`{ name: '另一首', bpm: 120, notes: [{m:60,t:0,d:1},{m:62,t:1,d:2}] }`
（m=MIDI 音高，t=起始拍，d=时值拍；常用 MIDI：C4=60 D4=62 E4=64 F4=65 G4=67 A4=69 B4=71 C5=72）。

## 简谱转曲目（`jianpu2song.py`）

把简谱写成 txt（每行一小节），用脚本直接转成 `songs.js` 曲段：

```
name=我的歌
key=mysong
bpm=100
0 5, 5, 1 1 2 3
0 5, 5, 1 1 2 3_ 2_ 1 5,
```

记号：`1` 四分（1拍）、`1_` 八分、`1__` 十六分、`1-` 二分、`1--` 三拍、`1---` 全音符、`1.` 附点四分、`1_.` 附点八分；`1'` 高八度、`1,` 低八度；`4#`/`5b` 升降号；`0` 休止符。小节不是 4 拍会报警。

**和弦（多键同按）**：同一时刻的几个音用 `+` 连写，游戏里会用金线把这几个球连起来；每个音可带自己的八度/升降号，时值统一写在最后一个音后面。

```
1+3+5         中音 1/3/5 同时弹，四分
1+3+5_        三个音同时弹，八分
6,+1+4        低音6、中音1、4 同时弹
4# 若在和弦里：1+3+4#+5
```

```bash
python jianpu2song.py mysong.txt                    # 默认直接写入 js/songs.js
python jianpu2song.py mysong.txt --print            # 只打印，不写文件
```

和弦判定：每个键独立计分，需要逐个按全；漏了其中一个会暂停等待，先按到同和弦的其他键也先计分（不影响其他和弦）。注入后在 `index.html` 把 `?v=` 缓存号加 1，再 Ctrl+F5 强刷。

## 加自己的歌

编辑 js/songs.js，按格式追加，下拉自动出现：

```js
mySong: {
  name: '歌名',
  bpm: 100,
  notes: [
    { m: 60, t: 0, d: 1 },
    { m: 62, t: 1, d: 1 }
  ]
}
```

MIDI 对照：C4=60，每升半音 +1；t 是起始拍，d 是持续拍数。
